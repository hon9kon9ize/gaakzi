# 格知（Gaakzi）

> 今日格一件，明日又格一件，積習既多，然後脫然自有貫通處。

「格物致知」推究事物的道理，方能獲得不盡的知識。語本《禮記．大學》。

- **格物**：搜集及整理香港本土與粵語相關實體、事件及文化脈絡
- **致知**：提煉成可查證、結構化的香港粵語知識圖譜與開放資料集

## 項目簡介

本專案（**格知 Gaakzi**）旨在建立一個可持續更新、附帶來源考據的**香港本土及粵語知識庫**，以**香港粵語書面語**（繁體中文）撰寫，並以結構化 Markdown 儲存實體關係與時間線，同時支援：

- **知識圖譜與 GraphRAG 檢索問答**（實體、別名、跨語言對照與關係網路）
- **大型語言模型（LLM）粵語預訓練與評測資料集**
- **社群協作、錯誤勘誤與事實更新**

## 目錄結構與條目格式

條目按標題首字分目錄存放於 `<首字>/<條目標題>.md`（例如 `大/大埔墟站.md`、`蔡/蔡天鳳.md`），每個檔案包含 YAML Frontmatter 與粵語正文：

```yaml
---
id: "<UUIDv4>"                # 系統指派的不可變唯一識別碼
title: "條目標題"
type: person | organisation | place | event | case
aliases:
  - "別名 / 簡稱"
external_ids:
  wikidata: "Q..."
  wikipedia_yue: "..."
  wikipedia_zh: "..."
parents:
  - "所屬分類或上級條目"
relations:
  - rel: "目標相對於本條目的關係（例如：創辦人、配偶、母公司）"
    target: "目標條目標題"
sources:
  - url: "https://..."
    from: "來源媒體或機構（2026-01-01）"
covered_until: "YYYY-MM-DD"   # 資料覆蓋截至日期
updated: "YYYY-MM-DD"
---
```

正文以香港粵語書面語撰寫，內部連結使用 `[[條目標題]]`，並以 `[^1]` 對應文末來源腳註。

## 如何參與貢獻與回報問題

歡迎大家透過 **GitHub Issues** 或 **Pull Requests** 一同完善本地文化與事實紀錄：

### 1. 提交 Issue（勘誤／補完／新增請求）
如發現以下情況，歡迎開立 Issue 並附上來源連結：
- **事實或日期有誤**：人物履歷、機構關係、時間線或數據出錯
- **資料過時**：條目 `covered_until` 之後有重要新發展
- **粵語用字或語體問題**：錯別字、書面語殘留或表達不自然
- **建議新增條目**：希望收錄的香港人物、機構、地點、事件或案件

### 2. 提交 Pull Request（直接修改或新增條目）
提交修改前請留意以下規範：
1. **保留既有 `id`**：已有條目的 UUIDv4 `id` 為知識圖譜主鍵，請勿修改或刪除。
2. **事實必有出處**：所有新增或改動的事實均須於 `sources` 及正文腳註 `[^n]` 附上可查證來源。
3. **香港粵語書面語與中立語氣**：使用自然、客觀的繁體香港粵語書面語，避免主觀評價或無根據推論。
4. **關係方向一致**：`relations` 中的 `rel` 代表「`target` 相對於本條目」的關係（例如在公司頁寫 `rel: 創辦人`、`target: 創辦人姓名`）。
